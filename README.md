# Welcome to **`reqmachine`**

> [!CAUTION]
> `reqmachine` is a Work In Progress (WIP)

## Install reqmachine
To install `reqmachine`, follow this:

```console
pip install .
```

## Use reqmachine
To use `reqmachine`, follow this:

```python
import reqmachine

...
```
## Use reqmachine with container (Docker/Podman)
To containerize `reqmachine`, follow this:

```console
docker build . -t reqmachine:0.0.1
docker tag reqmachine:0.0.1 reqmachine:latest
docker run reqmachine
```
